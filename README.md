\# EVENTA



EVENTA is a full-stack event planning platform designed to help users organize events from initial planning through the event day.



This project was inspired to help me plan and organize my own wedding.



\## Planned Features



\- Event management

\- Guest management

\- Vendor management

\- Budget tracking

\- Planning items and deadlines

\- Event timeline

\- Seating management

\- Event dashboard



\## Technology



\### Frontend

\- React



\### Backend

\- Java

\- Spring Boot



\### Database

\- PostgreSQL



\### Testing

\- JUnit

\- Spring Boot Testing
